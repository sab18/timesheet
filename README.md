### TO RUN
1. run `initialize.py` to generate following files: `Timesheet.xlsx`, `projects.yaml`, and `locations.yaml`.
2. input relevant information into `projects.yaml` and `locations.yaml`
3. run `executable.py`
4. create folder
5. copy `MyTimesheet_v.x.x.x.exe` to folder
6. also copy `projects.yaml`, `locations.yaml`, and `Timesheet.xlsx` to folder.
7. edit `digest` Sheet in `Timesheet.xlsx`.
